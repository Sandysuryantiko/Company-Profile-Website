# Portofolio – TB Abdul Fatah, S.H. & Rekan

Situs portofolio resmi untuk **TB Abdul Fatah, S.H. & Rekan**, sebuah kantor advokat dan konsultan hukum yang melayani berbagai kasus litigasi dan non-litigasi.  
Website live dapat diakses di: https://tbabdulfatah.netlify.app/

---

## 🏛 Deskripsi

Situs ini berfungsi sebagai media profil profesional, menampilkan layanan hukum, artikel hukum, dan cara menghubungi tim advokat.  
Beberapa fitur utama:

- Halaman Beranda, Tentang, Keahlian, Artikel, Kontak  
- Informasi bidang hukum: pidana, bisnis, perdata, agraria, keluarga, ketenagakerjaan  
- Blog / artikel hukum sebagai konten edukatif  
- Formulir / tombol konsultasi / kontak (WhatsApp, email, dsb)  
- Responsive (mobile / desktop)
